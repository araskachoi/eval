What do these numbers mean?

Total tokens = input + output. Cached input shows reused input tokens already included in that total. Cached output is not reported by our current adapter; it is not inferred from cache writes or reasoning tokens. Elapsed time is the recording window, not model response time.

Lines shows added (+) and removed (−) lines in the latest reported net change from the recording's starting point. Repeated edits and subagent changes are not added together. Older recordings without line data show Unavailable.

All sample counters, including line changes and costs, are scripted examples. The label sim-weather-v1 identifies our simulation and synthetic price table, not an AI model. No AI model runs in these samples.
